W/S and A/D are unchanged; R returns that participant to its assigned slot. RestartLevel reloads the grid/countdown; ProofGameMode.RestartRaceStart resets current participants through the same start authority.

Legacy paint/finish are reversibly hidden. Three legacy PlayerStarts remain inactive in their folder; exactly twenty GridStartSlot actors are active.

Geometry: source kart function produces width 162 cm, length 190 cm and height 142 cm including driver. The grid checks a larger 220x180x155 cm safety envelope. Ten staggered rows, 360 cm row pitch, 180 cm column stagger, offsets +/-210 cm; pole 1400 cm behind the finish for driver-height signal visibility. Individual 260x200 cm corner boxes use 8 cm painted lines and 52 cm position numbers. Paint follows source asphalt height, raised 2 mm, with no collision or grip change. Each native slot has editable PositionNumber, transform and KartSafetyHalfExtents. Numbers must stay unique 1-20; invalid layouts block staging. Native controller/participant assignment is deterministic. Existing ProofPawn participants can register before initial grid readiness with PreferredGridPosition or RegisterGridParticipant; no production AI/spawner was invented. Empty slots stay empty in normal Play.

Integration: one existing ProofGameMode state machine, timing and OnLightsOut event. All current participants stage with speed zero before the countdown: 2 s initial delay, five reds at 1 s intervals, 1.25 s all-red hold, simultaneous lights-out and release. No throttle-triggered second start. R uses the participant's assigned transform. Movement equations, input bindings and unrelated LocalKartDriverVisuals sources are unchanged.
