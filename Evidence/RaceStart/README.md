# Race-start display and single authority

Open Road_To_F1_New.uproject with UE 5.8.3, load /Game/RoadToF1/Maps/DesertKarting_Visual (or DesertKarting), then Play in Selected Viewport. Both maps now use the existing native ProofGameMode. The pawn stages at (-3400,200,31) cm facing +X; its saved PlayerStart is at Z40. W/S remain throttle/brake and A/D steering. R resets the pawn to the designated start; it does not start a second race. Reload the level to restart, or call ProofGameMode.RestartRaceStart from Blueprint. The latter is also an Exec function. The environment-only Blueprint game mode can still be selected as an explicit override for free-fly previews; it has no countdown.

Sequence: PRE_GRID -> COUNTDOWN -> ALL_RED -> LIGHTS_OUT -> RACING. All lenses off initially. Once all current player controllers have pawns, they are staged; first red after StagingDelay=2 s, additional reds every RedInterval=1 s, all-red hold AllRedHold=1.25 s. Properties are editable on a subclass of the existing game mode. FTimerManager one-shot callbacks drive the sequence; all owned timers are cleared on restart/end play. No per-frame countdown accumulation. LIGHTS_OUT sets the start timestamp, opens the single ProofPawn movement gate, broadcasts OnLightsOut exactly once and starts GetRaceElapsedSeconds. The HUD cue lasts 1.1 s and can be disabled. Optional sound slots and actor audio enable toggle are exposed.

This project contains only the temporary ProofPawn driving implementation, not the original RoadToF1 AI/lap/checkpoint simulation. No existing AI launch or lap-clock method was found to wire up. OnLightsOut is the single future integration point; no second race controller or invented AI system was added. The existing kinematic motion equations are unchanged. The current implementation is for the project's standalone driving mode.

Placement verified from saved Unreal actors: finish marker remains X=-1800 cm, display origin (-1840,0,0), lenses centered at Z560 cm and facing -X toward staged drivers. Five 75 cm housings on 95 cm centers mount to the existing 16 m gantry. Lowest new housing is about Z520 cm. All new display components and the actor have collision disabled. There are five independent lens MIDs, instanced housings, one support mesh, and no dynamic light actors. Old amber bulbs are reversibly hidden; circuit, painted grid, lights, terrain, checkpoints and start/finish are preserved. Of the three overlapping legacy starts located after the finish, one is now tagged RaceGridStart and staged before it; ChoosePlayerStart uses that actor deterministically.

Assets are original modeling, LED mask and synthesized click-free WAV beeps; no downloaded or paid content. Source Blender and FBX/PNG/WAV exports: Art/RaceStart. Runtime assets: /Game/RoadToF1/RaceStart. The existing source assets are unchanged. Pre-edit map checkpoints: /Game/RoadToF1/Checkpoints/DesertKarting_BeforeRaceStart and DesertKarting_Visual_BeforeRaceStart. Previous ProofPawn sources: Evidence/RaceStart/SourceBefore. Complete undo requires restoring those source files, removing the newly added RaceStartGantry C++ pair, rebuilding the module and restoring the checkpoint maps. Restoring source alone does not restore maps' native class references.
